# KINORA Balance — пошаговый запуск в PyCharm (Windows PowerShell)

## ВАЖНО
Открывайте **папку KINORA_Balance** — ту, где лежит `manage.py`. Если `.venv` находится на уровень выше, вместо `.\.venv\Scripts\python.exe` используйте `..\.venv\Scripts\python.exe`.

### 1. Создание окружения
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
### 2. База данных
```powershell
.\.venv\Scripts\python.exe manage.py makemigrations movies booking
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
```
### 3. Ваша учётная запись администратора
```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```
Введите собственный логин и пароль; пароль не публикуйте в GitHub. Админка: http://127.0.0.1:8000/admin/

### 4. Запуск
```powershell
.\.venv\Scripts\python.exe manage.py runserver
```
Главная: http://127.0.0.1:8000/; каталог: /movies/; будущие премьеры: /movies/upcoming/; регистрация: /tickets/signup/.

### 5. Тестирование сценария
1. В админке создайте/проверьте сеансы и залы (демоданные добавляются через `seed_demo`).
2. Зарегистрируйте обычного пользователя; войдите.
3. Откройте фильм с сеансом, выберите места.
4. Перейдите на страницу оплаты, выберите **демо-способ**, нажмите подтверждение.
5. Получите QR-билет в разделе «Мои билеты». Проверка QR доступна только staff-пользователю, а не гостям.

**Демо-оплата ничего не списывает.** Для реальных платежей потребуются договор с провайдером, API и верификация подтверждений платежа на сервере. Реальные площадки не подключены к продаже билетов.

### 6. Требования преподавателя
Рубежный модуль 1: отдельный архив/коммит с `data.py` без базы. Итоговый: Django ORM, CRUD, админка, профили и 3 типа связей, авторизация, деплой, README, ER-схема, 15 осмысленных коммитов. Эта версия — расширенная учебная заготовка; отдельные задания `Блог факультета` выполняются отдельно.
