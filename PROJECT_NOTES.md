# План продолжения

1. Подключить настоящий API расписаний **только с разрешением кинотеатров**; сейчас тестовые данные.
2. Интегрировать MBANK / Элкарт / Visa через официальный эквайринг; только после договора с провайдером. Не хранить карты на сайте.
3. Реальные платежи должны запускаться по созданному заказу, подтверждаться подписанным server-to-server webhook и только после этого менять статус.
4. Брони в demo сейчас удерживают места до ручной отмены. Для реального запуска нужны тайм-аут удержания, фоновая очистка и конкурентные блокировки на PostgreSQL.
5. Улучшить управление публикациями, отзывы, email подтверждения, возвраты, тарифы, проверку QR при проходе.
6. Тренировочные данные `seed_demo` не являются актуальной киноафишей.
